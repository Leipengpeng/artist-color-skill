# 同一原片，不同的成片愿望

以下仅用于用户明确请求文字提案时。默认成片任务使用作品双图路线，完成 LUT 后再演绎第一人称解读。

## 水面与小艇

画面里近处是深灰蓝水面，远处更浅，小艇的白浪清楚。两种愿望使用相同的构图、原色关系和白浪保护项。

### “下雨有点烦，想让这张图看完能松一口气。”

**莫奈 · 创作自述**

> 我喜欢那道白浪，它让我的眼睛在水面上停了一下，又能接着往远处走。在吉维尼，我反复画水面，留意的是一段颜色怎样接进下一段。我会把近处的灰蓝中间调轻轻托起一点，白浪留在它本来的亮度。这样再看向远处，那段水就好像走起来没那么费力了。

**调色指令**　轻抬已有的中间明度，保持色相次序和高光。保留白浪层次、远处浅水和小艇轮廓。对所有相同输入值使用相同映射。

**时期与资料**　晚期吉维尼的水面、反光和相邻光色。 [MoMA《睡莲》](https://www.moma.org/collection/works/80220)

### “想保留今天的重量，但还是希望图里有一点能停住的亮。”

**罗斯科 · 创作自述**

> 我喜欢这片深水给白浪留出的位置。看晚期黑与灰里的那段交界，浅处很少，却足以让人辨出暗面还有层次。我想把今天的重量留在近处这片水里。我会轻压尚有余量的低中调，保住水里的细小差别，也让那道白浪留在原来的亮度。

**调色指令**　轻压低中调，保持最深暗部的层次与原有色相。高光保持原亮度，保留白浪纹理。按输入明度范围全局处理。

**时期与资料**　晚期黑与灰的深浅关系。 [MoMA《无题》](https://www.moma.org/collection/works/79611)

## 用边界案例复查

| 输入和目标 | 应出现的取舍 |
| --- | --- |
| 暖灯橱窗、冷灰街道，希望有烟火气又隔着一点距离 | 霍普从已有亮暗和冷暖分界出发，温和拉开中间明度，保护亮面和人脸。若改成均匀漫射光且无可辨分界，就弱化处理或重选角色。 |
| 市场肖像，想强化橙外套，外套与要保护的肤色共享输入色域，原片还可分出中彩青绿背景 | 马蒂斯可转向已有青绿与中性间隔。若青绿也无法独立处理，就降低整个相关色域的改动。 |
| 带细纹的亮雪、岩面与暗树，希望成片清醒庄重，允许黑白 | 亚当斯预想亮部、中灰和深暗如何分层，全图输出中性灰。若原片有必须原值保留的彩色标志，报告全图黑白与保护项冲突，并在保色的前提下另评可行路线。 |

比较时记录哪个输入条件改变了角色或动作，再核对成片上的实际变化。生成实验分别检查几何、LUT 复刻和调色幅度，情感贴合由用户审阅实际 LUT 成品。
