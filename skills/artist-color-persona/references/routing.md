# 艺术家与真实作品的选择

使用 [active-personas.json](active-personas.json) 中的十位角色；详细理念和资料见 [personas.json](personas.json) 及角色的 `dossier`。这些资料用于选人、选画和成片后的解释，不作为附加文字塞进 Image。

## 1. 先处理明确选择

| 用户输入 | 本次动作 |
| --- | --- |
| 只给原片，要求自动选 | 按可见线索从十位中选一位，再选其真实作品。 |
| 点名名单内艺术家 | 固定该艺术家，选择适合原片的作品；不自行换人。 |
| 点名时期或具体作品 | 优先使用该时期或作品；记录真实年份和来源。实际作品时期可能不同于角色卡的主参照时期。 |
| 提供一张画作参考 | 查看图像并核对作者、作品记录。作者与点名不一致时说明冲突，不能把画作改记为另一位作者。信息不足则记为“用户提供的参考图”，不编造作品名。 |
| 要求同图多位对比 | 固定全部点名角色；对每位独立选画、生成和拟合。原片保持相同。 |
| 点名名单外人物 | 说明固定名单不含此人；可根据描述在现有角色中提出近似方向，明确身份仍是名单内角色。用户另行要求研究或扩充时才搜索新人。 |

## 2. 读取可见证据

用三至五句记录主体与观看重点、已有光区、主要色组、用户目标及明确保护项。例如：近处黄橙叶与远处蓝水；阳光墙面与棚下阴影；近灰器物与米白背景。不要发明原片没有的灯光。

未说明目标时，从画面推断一个方向并标注“本次推断”；不把天气或颜色当成固定情绪字典。用户要求准确色值、自然肤色、产品色或告警色时记录这些硬条件。没有这类要求时，不自行添加“必须自然／克制”的限制。

全局 LUT 对同一个输入 RGB 使用同一个输出 RGB，不能按物体身份、位置或一片叶子单独赋色，也不能改变构图、增加笔触或移动光源。这个边界影响拟合说明，不表示强烈配色不可用。

## 3. 十位艺术家的可观察入口

下表用于生成候选，不是按题材贴标签。每位都可处理多种题材，最终依据是原片关系和所选真实作品。

| 角色与 ID | 优先考虑的可见线索／目标 | 选画与解释重点 |
| --- | --- | --- |
| 霍普 `hopper_urban_light` | 墙面、窗、人物或室内与环境已有清楚光区；希望突出观看距离、城市空间或疏离感。 | 比较受光面与阴面的冷暖和亮度分量；区分日光／人造光作品，不能一律加冷蓝代替空间关系。 |
| 马蒂斯 `matisse_cutouts` | 已有几组清楚颜色或色组与浅底；希望鲜活、明快、互相呼应。 | 比较邻色的分量，强烈颜色可保留；剪纸形状和重新摆放不由 LUT 完成。 |
| 莫奈 `monet_giverny_late` | 花叶、水面、空气或反射已有相邻光色；希望突出连续、柔和或明亮的变化。 | 按具体作品比较光色联系，可有浓郁版本，不自动等于低饱和；安提布作品不能称为晚期睡莲。 |
| 罗斯科 `rothko_black_gray` | 大面积深色或横向色面有内部层次，与亮色形成参照；希望集中、沉静或有重量。 | 区分晚期棕灰与早期／经典彩色色域，解释色场分量，不从画面反推作者心理。 |
| 亚当斯 `adams_zone_print` | 原片有纹理、暗部、中灰与亮部，且黑白符合用户目标。 | 选黑白印相参考，输出中性黑白 LUT；区分影调思路与局部暗房加减光。不能交彩色调色却称为本角色路线。 |
| 莫兰迪 `morandi_mature_still_life` | 近色器皿、花瓣、桌面或背景靠小幅明暗和材料偏色区分；希望含蓄、亲密、安静。 | 比较相邻面如何分开，不把全部照片统一涂灰；区分成熟静物与早期形而上阶段。 |
| 梵高 `vangogh_auvers` | 田地、建筑、植物或人物已有可对置色组；希望显著表达情绪、活力或并存的感受。 | 选定作品决定主色和对照色；不把所有时期概括为黄蓝，也不把情绪等同不断加饱和。 |
| 夏加尔 `chagall_vitebsk_memory` | 人、家、街道或物件承载用户说出的记忆；已有颜色可突出记忆支点。 | 作品颜色服务于本次叙事；漂浮、倒置、视点重组属于构图，不能由 LUT 保证。 |
| 塞尚 `cezanne_color_planes` | 花瓣、果实、山体、建筑的相邻冷暖或中间调正在说明转面、体积与纵深。 | 选能说明色面关系的作品，不只按静物题材选，也不把立体主义标签直接当其身份。 |
| 高更 `gauguin_pont_aven` | 已有大主色面和可分对照色；希望用集中主调或非自然色增强表达。 | 比较具体作品的主色与深浅分量；浓烈和非自然色可用，不把全部时期简化为热带配色。 |

## 4. 做一次可复查的选择

自动选择时找最有证据的两至三位候选，各写一条“原片线索 → 与角色的关系”，再按以下优先级选一位：

1. 回应用户明确目标或偏好。
2. 与原片已有光色关系相符，而非必须改构图才成立。
3. 在该角色的已收录真实作品中有清楚的参考关系。
4. 仍相同时，优先来源和作者可核对的作品；完全并列时按角色 ID 字典序，记录为平局规则，不假装唯一最佳。

不要求冗长推理链或虚构数值评分。保存最终角色、关键原片线索、选画理由和来源即可。陌生题材（OOD）也按这个方法分析，通常无需在线搜索新艺术家。

原片可见但线索很弱时，可用莫奈作为默认起点，明确这是本次默认选择；具体力度仍由真实参考画决定，不自动降为“几乎不变”。图片无法查看时先解决查看问题，不据文件名选人。要求保留全部输入色值与风格迁移冲突时说明不能同时满足，不把无变化冒充明显风格化。

## 5. 在选定艺术家内挑真实作品

1. 从 [index.json](../assets/artworks/index.json) 找 manifest。八条作品记录是候选元数据，不保证八张图都随公开包附带。
2. 用题材、光线质量和可分的冷暖／深浅关系筛一至两幅；题材相同但颜色关系无关不优先。
3. 取得并查看实际作品文件。公开包缺图按 [作品获取](artwork-image-lut.md#取得真实作品文件)处理，不能因此把自动选择偷偷缩回莫奈。
4. 记录准确标题、作者、年份、来源、文件与一句匹配理由。资料与画面不一致时先核对，不给陌生图强贴作品名。
5. 第二输入是画作本身。艺术家肖像、合影、展览现场、多图网页截图、之前生成的样稿都不能冒充作品；PDF 或展览页需取得清楚的单幅作品图。

本次参考作品及其颜色强度优先于概括性标签。角色卡和生平资料帮助说明作品，不改写实际身份，也不在成片之前额外限制 Image。
