# 艺术家调色 Skill

默认顺序：**看原片 → 选艺术家 → 选该艺术家的真实作品 → 双图 Image 迁色 → 拟合并应用 LUT → 艺术家解释成片**。人物对白不参与前面的 Image 提示词。鲜艳、高饱和、明显色偏及局部浓色可以是风格表达，不单独视为缺陷，也不因此自动减弱效果；美学由用户判断。

## 先确认任务和能力

- 用户已给原片就开始；没有可读取图片时，只请求缺失原片，不凭文件名假装看过图。
- 自动选择使用 [十位名单](references/active-personas.json)。用户点名某位、指定时期、指定真实画作或指定比较组合时，优先遵循这些选择。名单外请求按 [路由规则](references/routing.md)处理，不自动搜索或新增角色。
- **完整调色需要三项能力：**读取并查看两张图；同次提交两图进行图像编辑、取得真实返回文件；运行 Python 并保存、交付文件。能力缺失时说明实际完成阶段，不把文字方案或 Image 样稿称为 LUT 成片。豆包及其他宿主先读 [豆包执行说明](references/doubao-workflow.md)。

## 执行步骤

1. **识图并选人。** 记录主体、现有光线、两组主要颜色或明暗关系及用户目标。按 [路由规则](references/routing.md) 从名单选择一位；不要只看“风光／人像”的题材标签。
2. **选一幅真实作品。** 从 [作品索引](assets/artworks/index.json) 找该艺术家的 manifest，结合本次光色关系选择并实际查看作品图。记录艺术家 ID、作品名、年份、来源、选画理由和本地文件。公开包保留 80 条作品记录，但只附已确认可分发的图像；其余按 [作品获取步骤](references/artwork-image-lut.md#取得真实作品文件) 获取到私有缓存或导入用户文件。未随包分发不等于该艺术家不可选。画作本身才是第二张输入，不能换成生成图、拼贴或艺术家的肖像。
3. **准备和生成。** 按 [双图与 LUT 命令](references/artwork-image-lut.md)执行 `prepare`，读取实际 `job.json`。同一次 Image 编辑按顺序提交其 `image_inputs`：图 1 原片、图 2 真实画作；发送 `prompt.txt` 原文，不加入人物生平、对白或额外稳定性约束：

   ```text
   Image 1 is the content photo. Image 2 is the color reference. Match the colors of Image 1 to Image 2.
   ```

4. **拟合并导出。** 保存本次 Image 的实际返回文件，再用 `finish` 拟合全局 LUT、重读 `.cube` 并应用到原尺寸照片。检查实际 `result.json` 指向的 LUT 和成片文件。返回图重绘时照实保留，最终 LUT 仅迁移颜色，不把新物件、笔触或局部重绘算入成片。
5. **成片后解释。** 最终 LUT 照片存在并已查看后，才读 [人物解读](references/voice.md)。角色读取原片、实际画作、Image 返回、LUT 成片及拟合记录，用第一人称简明说明可见的色彩关系、相关创作理念和本次结果。称呼用艺术家姓名；整体说明一次“基于作品与资料的角色模拟，并非历史原话”。使用实际参考作品的时期，不能把卡片主时期套到另一时期作品上。
6. **交付。** 按 **00 相机原片、01 真实参考画、02 Image 生成效果、03 原尺寸 LUT 成片、04 对应 `.cube`** 的顺序展示或整理文件，并附作品来源、实际 Image 提示词、人物说明和任务记录。所有文件链接指向实际存在的交付文件。中间样稿与最终照片分别标明。

## 对比、追问和恢复

- **同图两位或多位艺术家：**保持同一原片字节；每位各选自己的真实画作、各建独立任务目录、各完成 Image 与 LUT。全部成片完成后再组织人物对话；根据实际区别解释，不为口播预设的对立强造差异。
- **用户只追问已经完成的调色理由：**读取原任务资料和成片，直接走后置解读，不重新生成。用户明确只要文字对话或方案时，使用 [文字模式](references/voice.md#仅在用户要求文字方案时作决定)，明确尚未调色。
- **同版本中断：**保留 `job.json` 和已有文件，按 [恢复表](references/artwork-image-lut.md#中断与失败处理)继续缺失步骤。更换原片、作品或 Image 返回，创建新任务目录；不覆盖旧版本。
- 只有用户明确要求“直接把画作统计追色到原片”时，才使用直接追色路线并单独标明。它不等于本 Skill 默认的“双图 Image 后拟合 LUT”。
